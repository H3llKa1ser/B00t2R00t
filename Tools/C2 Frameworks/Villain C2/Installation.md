# Villain C2 Installation

## Apt (recommended)

### 1) Install via apt

    sudo apt install villain

### 2) Launch

    villain

## Git repo

### 1) Clone repository

    git clone https://github.com/t3l3machus/Villain

### 2) Inspect files

    cd villain
    ls -la

### 3) Launch Villain

    python3 Villain.py
