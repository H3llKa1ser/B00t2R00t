# Covenant C2 - Usage

### 1) Create listener

Go to:

    Listeners -> Create

Give it a name, set a specific profile for the Listener, the give it your address to connect back and port number.


### 2) Create Launcher

Go to:

    Launchers

Then, select a type of payload you want to generate, then click both Generate and Download to our local machine.

Transfer the payload as you see fit, then GG, you got a connection!
